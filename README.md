## Project Title

AI Research Workspace

## Project Description

AI Research Workspace is an NLP-based research paper assistant
that uses Retrieval-Augmented Generation (RAG), local semantic
embeddings, FAISS vector search, and the Gemini API.

Users can upload research papers and ask questions about them
using natural language.

## AI Research Workspace

The project uses the following pipeline:

PDF → Text Extraction → Chunking → Embeddings → FAISS →
Similarity Search → Gemini → Answer + Citations
